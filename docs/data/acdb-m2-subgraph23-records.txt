wire stride is 16 + align8(8) = 24 B and the whole payload is 240 B => ONE in-band SET_CFG
carries the entire table: no out-of-band, no chunking, and none of the 18 KB object.
Multi-record => dst = APM = 1, same handle as the L rounds.

Honest limit: this changes length AND param AND per-record size AND the iids at once, so M2
is only readable next to M1 (C's container with only the param swapped).  It is not a
single-variable shot and must not be scored as one.
